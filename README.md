# 简账 Lite

**一款简单、免费、轻量的个人记账工具。**

做这个项目的初衷很简单：希望有一个用起来方便、不需要复杂操作，也能清楚了解自己日常开销的记账工具。

不需要注册账号，没有复杂的操作流程。打开软件，记录一笔收入或支出，就能逐渐看清自己的钱花在了哪里。

目前项目还处于早期开发阶段，功能和界面都还有不少可以改进的地方，但基本的日常记账需求已经可以满足。

## 主要功能

- **日常记账：** 记录收入、支出，支持修改和删除账单。
- **消费统计：** 按月份和消费类别查看开销。
- **预算管理：** 设置每月预算，查看剩余可用金额。
- **个性化界面：** 自由更换主题、字体和按钮样式。
- **本地数据保存：** 记账数据保存在当前设备的浏览器中。
- **数据备份：** 支持 JSON 备份、恢复及 CSV 导出。
- **手机端使用：** 适配安卓手机浏览器，支持添加到主屏幕。

## 在线体验

[点击体验简账 Lite](https://upyuwentuo1.github.io/-/)

安卓用户可以使用 Chrome 浏览器打开网站，通过浏览器菜单中的「安装应用」或「添加到主屏幕」创建桌面入口。

目前主要提供网页版和 PWA 版本，并非原生 APK。

## 使用须知

目前软件仍处于测试阶段，部分功能可能存在不足。

记账数据主要保存在本机浏览器中，清除浏览器数据、更换设备等操作可能导致账单丢失。建议定期导出备份。

如果你发现 Bug，欢迎在 GitHub Issues 中反馈。
